Convert CAJ, KDH, PDF, HN, or C8 in the browser

The selected file is read through bounded Blob.slice() ranges. The PDF is streamed to a file you choose (showSaveFilePicker) or, where that API is missing, to a private OPFS file offered as a download. HN/C8 rendering is experimental. Conversion uses a Dedicated Worker and OPFS, with four scratch files capped at 64 MiB each and removed before completion.
