Bundled font data v1
====================

The converter source is MIT-licensed. The font programs are separate assets,
not covered by the converter source license. Their original names, outlines,
metrics and embedded notices are preserved byte-for-byte.

Nine resource fonts originate from CAJViewer 7.3.151 Simple, TTKN Resource/cajfonts.
The SimSun collection is the system font used in the retained Wine experiments.
Only face 0 is selected. This pack is concatenated original data, with offsets
and SHA-256 identities in font-pack.json. It contains no document samples.
