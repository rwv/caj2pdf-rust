The consumed v11 create arguments contain no such public-module bind. A

freeze before execution. A metadata-only plan edit cannot change hardcoded
host arguments. No additional phase has run.

No repository recipe defect is established by the module's absence from a
bare image. The initial unposted install-child proposal is superseded by this
transport evidence and remains external as a planning correction.
