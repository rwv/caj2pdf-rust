# v0.6.2 — classic-Worker bundling fix

## Worker without top-level await (#433)

- `js/internal/worker.mjs` no longer selects its message channel with a
  top-level `await`. Bundlers such as Vite (Rolldown) that emit Workers in the
  default `iife` format can now build applications importing `caj2pdf-rust`;
  previously production builds failed with "Top-level await is currently not
  supported with the 'iife' output format".
- The browser branch stays synchronous. In Node, messages posted before the
  listener is attached are buffered by the `MessagePort` until it starts.
- `js/test/worker-startup.test.mjs` statically rejects a top-level `await`
  anywhere in the Worker module graph and checks Worker startup on Node.

Applications carrying a local patch for this issue (for example
`patches/caj2pdf-rust@0.5.0.patch`) can drop it after upgrading.

## Scope and upgrade

This patch is cut from the v0.6.1 tag on `release/v0.6.x` with only the
#517 fix and version metadata. There are no API, CLI, WASM ABI, PDF output,
supported-format or dependency changes since v0.6.1, and upgrading needs no
migration. The breaking changes already on `main` (TEB inspection reason,
spool cleanup `AggregateError`, Rust native-font fields) are not included;
they ship in v0.7.0. Use matching JavaScript and WASM versions.

## Validation scope

The fix was reviewed and merged on `main` in #517, with external Vite 8
`iife` builds and Node/Chromium control matches recorded there. On this
release branch the full JavaScript suite, including real Chromium and the
packed tarball, passed locally before tagging (167 tests, zero skipped), and
the tag workflow repeats the native/WASM quality gates, the complete platform
matrix, the actual npm tarball tests and attestation verification before any
registry upload. Optional external-corpus checks without inputs are NOT_RUN;
no new corpus run is claimed for this version bump. Remaining unsupported
inputs and fidelity limits are those of v0.6.1. Windows/macOS binaries remain
unsigned. See [build provenance](../build-provenance.md).

```sh
cargo install --locked caj2pdf-cli --version 0.6.2
cargo add caj2pdf-core@0.6.2
npm install caj2pdf-rust@0.6.2
```
