# v0.2.0 — native platforms and Docker

Unstable MIT Rust CAJ-family converter with bounded input/scratch, sequential
output, a native CLI and browser/Node WASM APIs. This release expands delivery;
format support and PDF encoding remain unchanged from v0.1.0.

## Native downloads

Each `caj2pdf-v0.2.0-<target>` archive contains the executable, README, project
license and selected MIT dependency notices. Windows uses `.zip`, others
`.tar.gz`. Choose the target matching your OS and architecture:

- Linux GNU: x86_64, aarch64, i686, armv7 hard-float, riscv64gc, powerpc64le, s390x.
- Linux musl (static): x86_64, aarch64.
- macOS: x86_64 and aarch64.
- Windows MSVC: x86_64, aarch64 and i686; statically linked MSVC CRT.
- FreeBSD: x86_64 and aarch64.

Linux GNU builds use Ubuntu 24.04/glibc 2.39 sysroots. macOS tests run on version
15, Windows on Server 2025/Windows 11, FreeBSD in 14.3 VMs. Extended Linux
architectures execute under QEMU; see `docs/platforms.md` for precise scope.
Binaries are unsigned/not notarized. Compilation does not establish support
for older OS versions, all physical CPUs or targets outside the listed matrix.

## JavaScript and containers

- `caj2pdf-rust-0.2.0.tgz`: Node 22+ and browser package with WASM and declarations.
  Install with `npm install ./caj2pdf-rust-0.2.0.tgz`.
- `caj2pdf_wasm.wasm`: standalone module; use the JS adapters for ranged I/O.
- `caj2pdf-container.oci.tar`: tested multiarch Linux amd64/arm64 container archive.
- `CONTAINER-DIGEST.txt`: manifest digest published to
  `ghcr.io/rwv/caj2pdf-rust:v0.2.0`; see `docs/docker.md` for mounts and scratch.
- `SHA256SUMS`: hashes of all release assets. Run `sha256sum -c SHA256SUMS`
  after downloading the assets together.

The container runs as a non-root user on scratch, with no shell or service.
Use a writable output mount and `/tmp` (explicit mode 1777 for tmpfs). Large
inputs should use disk-backed temporary storage rather than memory-backed tmpfs.
OCI archives are available independently of registry access. No npm/crates.io
publication or Docker Hub mirror is included.

## Support and checks

CAJ/PDF/KDH are supported within documented profiles. HN/C8 remains experimental
with known viewer-pixel/geometry limits. C8/HN-B requires `--no-bookmarks`;
unsupported/image-less rows fail explicitly. No OCR, searchable HN or TEB support.
Known Python-reference differences and missing corpus (`NOT_RUN`) remain visible.

All declared targets must pass core units and real CLI conversion/pipe/cleanup
checks before publication. Release also requires the existing native, WASM,
MIT/advisory and exact 100% Linux Rust line-coverage gates. Windows-only code has
separate native execution tests; 100% coverage across all OSes is not claimed.
Container manifests are tested from the exact OCI archive subsequently uploaded.
