# v0.1.0

First unstable release of the MIT Rust converter, with ranged input, sequential
output, bounded scratch storage, a Linux CLI and browser/Node WebAssembly APIs.

## Downloads

- `caj2pdf-v0.1.0-x86_64-unknown-linux-gnu.tar.gz`: CLI, MIT license and README.
  Built and tested on Ubuntu 24.04 x86_64 (glibc); no macOS, Windows, ARM or
  older-glibc binary compatibility is claimed.
- `caj2pdf-rust-0.1.0.tgz`: installable JS package with WASM, declarations and
  browser/Node entry points. Install with `npm install ./caj2pdf-rust-0.1.0.tgz`.
  Node 22+; browser conversion uses Workers and OPFS for bounded scratch.
- `caj2pdf_wasm.wasm`: standalone module; use the JS package for its I/O adapters.
- `SHA256SUMS`: run `sha256sum -c SHA256SUMS` beside the downloaded assets.

This GitHub prerelease does not publish to npm or crates.io. The package's
private flag only prevents registry publication; local tarball installation works.

## Support and compatibility

CAJ, PDF and KDH work within the documented profiles. HN/C8 image conversion is
experimental: selected viewer pixels still differ, physical units are empirical,
and C8 requires explicit bookmark omission. Unsupported layouts and image-less
source rows fail explicitly. No OCR, searchable HN or TEB support is promised.
Rust retains source page-table order and valid bookmarks; known Python differences
and missing optional corpus (`NOT_RUN`) are recorded in `docs/conformance.md`.

## Unstable APIs and migration

v0.x may introduce breaking changes. See `CHANGELOG.md` for development API/CLI
migrations. Bilevel PDF streams now use Flate: output bytes/hashes change, and
conversion requires at least 512 KiB `max_allocation_bytes` for the compressor.
Default limits already satisfy this. Built-in QM/MQ states need no caller table;
use `withHnc8Scratch` for bounded Node/Worker scratch lifetime.

## Validation

Release publication requires native quality checks, real Node/Chromium package
tests, MIT dependency/source/advisory audits and 100% Rust line coverage. The
uploaded JS tarball is the one exercised by extracted-package tests. The CLI is
smoke-tested with an original synthetic PDF and qpdf. External sample documents,
vendor software and viewer captures are not included in release assets.
