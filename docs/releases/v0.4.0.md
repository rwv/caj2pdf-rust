# v0.4.0 — HN/C8 conversion improvements (unreleased draft)

This is preparation for #222, not a published release or completed acceptance
report. Package versions and release tags have not changed. #221 still needs
nonempty source-stored HN-B/C8 bookmark evidence. Final integrated artifacts,
full release matrix and attestations remain pending.

## Conversion scope

- HN-A: verified paired raw/compressed framing, per-page dimensions and marked
  image coordinates. The recorded corpus passes 19/19 HN-A inputs; this does
  not establish universal HN-A support or full viewer pixel parity.
- HN-B: admitted mode-0/mode-2 native text profiles and both verified index
  layouts. Three selected documents have complete 4/4/6-page runtime checks.
  Mode-2 leading images are supported; images after text and mode-0 images
  remain explicit errors.
- C8: the admitted six-page profile and additional four/five-page profiles
  preserve native text, drawings and descriptor-ordered images with explicit
  caller fonts. Required unknown records or missing glyphs fail explicitly.
- CAJ: bounded interrupted-object and stream recovery admits independently
  validated complete copies. Corrupt or ambiguous content still fails.

HN-B/C8 conversion requires explicit bookmark omission (`--no-bookmarks` or
`includeBookmarks: false`). Unknown outline metadata is not a confirmed empty
TOC. Fonts are caller resources, not included vendor assets. Image-only pages
receive no OCR. See [current support](../conformance.md#current-support-and-release-status),
[CLI font options](../cli.md) and [Node/browser usage](../../js/README.md).

## Breaking changes and migration

v0.x is unstable. These changes affect direct Rust users and custom WASM hosts;
the bundled JS adapters handle resource routing.

| Surface | Change and migration |
| --- | --- |
| Rust toolchain | Minimum Rust version becomes 1.88.0. Update older toolchains before building. |
| `C8PageFonts` literals | Add `symbols`, `latin_state3`, `latin_state28`, `latin_state31`; use `None` for absent optional roles. Rendering that requests a missing role fails. |
| `hnc8::Header` literals | Include `native_origin` and `native_mode` from parsed metadata rather than inventing values. HN-B `native_origin` and `page_size` can now be `Some` even for zero extents; their presence is not a renderability test. |
| `TextCoordinates` literals | Include `page_size`. Admitted paired HN-A pages now use verified page dimensions instead of always inheriting the document header; output geometry can change. |
| `NativeRecord::End` | `value` becomes `Option<u16>`; wrap explicit old values in `Some` and handle `None` as an absent payload. |
| Exhaustive native-record matches | Handle added `ImageReference`, `ExtendedControl` and `EncodedString` events. Updated C8 drawing framing preserves following controls separately, changing visitor event counts. |
| Rust WASM engine | `Request::Read` includes `resource`; route document and font reads to the registered source. `Engine::set_c8_fonts` adds the symbols argument (`u32::MAX` when absent). Existing raw WASM font-setter exports remain available. |
| Invalid HN-B input | Unknown layout markers and invalid compact-index fields are rejected explicitly; do not rely on permissive parsing. |
| Damaged CAJ streams | Flate Length recovery now validates the compressed stream. The recorded issue-20 input changes from a warning-producing old output to explicit rejection; no unchecked repair fallback is provided. |

For exact resource registration and extended font roles, use the
[I/O and ABI reference](../io-architecture.md). See the
[changelog](../../CHANGELOG.md) for the implementation history; early research
milestones there do not override the current support summary.

## Evidence and limits

The merged #267 checkpoint ran all 56 fixed corpus inputs: 38 had at least
one successful conversion, versus 34 previously. That font-free run is
separate from explicit-font HN-B/C8 validation. External documents, fonts,
captures and copied text stay outside Git and release assets.

[Unicode evidence](../research/hnc8-text-fidelity.md) separates glyph transport from
independent source checks, extraction order, spacing and visual appearance.
Marker-font or adapter-hash agreement does not establish original-font pixel
parity. Missing optional evidence remains NOT_RUN.

[Conformance evidence](../conformance.md) records representative native RSS,
WASM high-water capacity, bounded requests and scratch peaks. These are
measured cases, not a universal memory bound. Ranged input, sequential output,
forward-only spooling and failure cleanup remain the conversion model.

Current main lists 53 native OS/CPU/ABI targets, adding i586 GNU and FreeBSD
RISC-V64/PowerPC64 to the historical 50. Baselines are documented in
[platforms](../platforms.md). The JS tarball, standalone WASM and existing OCI
archive remain part of the release set. No npm/crates.io publication is implied.

Before publishing, complete #222 against the chosen versioned candidate:
inspect the actual archives and packaged Node/browser output, require the

publication acceptance. Pending rare-platform checks are not passes.

Follow the existing [provenance verification guide](../build-provenance.md).

historical published assets are replaced.
